# Capstone Design

## Problem

Businesses need a simple way to embed lead-capture widgets
on external websites without building the backend themselves.

## Users

### Widget Owner
Creates and manages widgets and views submissions.

### Website Visitor
Interacts with an embedded widget and submits information.

## Core Flow

Owner → Widget API → Database

Customer Website → widget.js → Config API

Visitor → Submission API → Validation → Rate Limit
→ Spam Check → Geo Enrichment → Database
→ Side Effect

Tenant isolation
Input validation
CORS

## Non-goal

This project will not implement a production-grade
visual form builder or real CDN hosting.
